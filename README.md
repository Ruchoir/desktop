# Ruchoir desktop

The desktop app for Windows, macOS and Linux: a light Tauri shell that opens each product of
your Ruchoir instances in its own window, with notifications and local copies of drive files.

> In construction: part of the restructuring of Ruchoir into separate products. The app moved here
> from `Ruchoir/ruchoir` with its history; its shell is rebuilt as a launcher opening each product
> in its own window. Layout: [`AGENTS.md`](AGENTS.md).

- How to work here: [`AGENTS.md`](AGENTS.md), which opens with the common rules of the organization.
- How to contribute: [Ruchoir/.github, `CONTRIBUTING.md`](https://github.com/Ruchoir/.github/blob/main/CONTRIBUTING.md).
- Decisions that span several repositories: [Ruchoir/.github, `docs/adr`](https://github.com/Ruchoir/.github/tree/main/docs/adr).
